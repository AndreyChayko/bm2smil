Convert Lottie (Bodymovin) JSON to pure SVG

This tool converts Lottie (Bodymovin) animations into pure SVG with SMIL animations. The server processing is powered by the bodymovin-to-smil library.

It supports basic animations:

  • masks (additive and intersect)
  • shapes
  • solids
  • texts
  • precomps
  • transforms
  • opacity
